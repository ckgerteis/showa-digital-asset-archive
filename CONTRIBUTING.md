# Contributing

This repository is a link index and metadata register for 3D models of material culture in Shōwa Japan (1926–1989), for teaching, game building and heritage reconstruction. It holds no model files.

## What to submit

Use the form on the site's Submit page, or open an issue, with:

- the URL of the listing page itself (Sketchfab, Fab, CGTrader, Unity Asset Store or an institutional repository);
- the licence exactly as the listing states it (CC BY, CC BY-NC, Standard, Editorial, view only, and so on);
- a short statement of historical fit, including what might be anachronistic;
- any XR performance notes you have (scale, LOD, texture sizes, formats).

Listings under any licence are welcome. Every submission is checked against its listing before it enters the catalog, and the record is built from the listing, never from the submission text alone.

## What not to submit

- Model files or textures copied from any listing.
- Repackaged downloads meant to stand in for the listing.
- Models generated by AI whose listing does not say so.

## Pull requests

Edit `catalog/fab.yml` following the README, and run `python scripts/validate_catalog.py` before opening the pull request. Leave `showa_fit` as `unassessed`; the curator sets it. Read `ethics.html` for how AI tools may and may not be used in preparing an entry.
